# React Joke Generator

🚀 Live Demo: https://react-joke-generator.onrender.com

## Description
A fun web application built using React that generates random jokes by fetching data from a joke API. The application demonstrates API integration and dynamic UI updates using React state.

## Features
- Generate random jokes
- Fetch jokes from an external API
- Dynamic UI updates with React
- Simple and responsive design

## Technologies Used
- React
- JavaScript
- HTML
- CSS
- Joke API
